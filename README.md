# Excel Merge & Data Cleaning with Python Pandas

This project demonstrates how multiple Excel files were merged and cleaned using Python and Pandas.

## Tasks completed

- Combined multiple Excel datasets using pd.concat()
- Identified duplicate records and missing values
- Corrected invalid data types
- Cleaned and validated merged dataset
- Exported final cleaned Excel file successfully

## Files

sales_jan.xlsx → January dataset

sales_feb.xlsx → February dataset

sales_mar.xlsx → March dataset

clean_merged_sales.xlsx → final cleaned dataset

excel_merge_cleaning.ipynb → full workflow
